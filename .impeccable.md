## Users

One person, job hunting for entry-to-mid **design** and **engineering** roles.
Sessions are long, repeated, and skew evening. The tool is opened many times a day
across weeks — this is a high-frequency instrument, not a destination.

**Job to be done:** *"Show me what landed since I last looked, in under two minutes,
so I can pick three things to apply to."* Everything else is secondary.

## Brand Personality

Three words: **unsentimental, fast, forensic.**

Not "modern," not "elegant," not "premium." The physical object this resembles is an
airport flight-strip board or a lab instrument readout — something that reports state
without editorializing. It never celebrates. It never nudges. It shows the rows.

## Aesthetic Direction

**Instrument-dense.** ~30 rows visible without scrolling. Hairline rules, not cards.
Tabular figures so timestamps and pay ranges align down the column. Chrome recedes
entirely; the data is the figure and the UI is the ground.

**Theme:** light only, like Postie. The dark theme and its toggle were removed on
2026-10-25; `lib/contrast.test.ts` fails if a dark palette comes back half-built.

**Anti-references:**
- LinkedIn Jobs — the thing being escaped. No feed, no engagement surface, no "people also viewed."
- The generic SaaS dashboard — no stat tiles, no sparklines, no gradient hero metric.
- Marketing-page choreography — no scroll reveals, no magnetic buttons, no perpetual motion.

**The one memorable thing:** everything that LANDED in the last 24 hours occupies its own
band at the top of the table, and nothing on the page competes with it for attention. The
single accent color exists to mark that band and nothing else.

> **Amended 2026-08-28.** Was: *"the last 24 hours occupies its own band"*, keyed to
> `posted_at`. That is the date the ATS created the requisition, which for an internship is
> routinely months before anyone can apply — so the band could only ever hold a handful of
> rows while a hundred genuinely arrived today. The job to be done above says *"show me what
> **landed** since I last looked"*, and landed is a fact about this board's ingest. Commit
> `8c9d01c` already conceded the distinction for the 60-day cutoff and failed to carry it
> through to the display, which left the band labelling rows whose own cell read `668d` on
> 95% of engineering rows.

## Design Principles

1. **Density is the feature.** Any change that reduces visible row count needs to buy
   something specific. Padding is not a feature.

   > **Amended 2026-10-25.** Postie's sheet (14px text, 11px × 12px cells) shows fewer rows
   > than the old 11px table. That is the price of one design system across both apps; do
   > not fork a denser variant.
2. **One accent, one meaning.** The accent marks *fresh*. It is never decoration, never
   a brand flourish, never a second button style.

   > **Amended 2026-10-25.** The accent is Postie's link blue (`#0a66c2`): it colours links
   > (Apply) and a fresh row sits on Postie's unread tint (`#f5f9ff`). Lime (`--primary`) is
   > the one primary button and never carries text on white.
3. **Motion only where it explains.** Frequency decides. Something touched 50×/day gets
   zero animation; something touched 5×/day may get 200ms. Three animations total in the app.
4. **Badges are controls.** Every badge is a live filter value — it must read as pressable
   without shouting. A row carries exactly three kinds of affordance: its badges, the company
   cell that opens the drawer, and Apply. Nothing else enters a row, and nothing in a row
   opens a popover.

   > **Amended 2026-08-28.** Was: *"This is the only interactive affordance inside a row
   > besides Apply"* — false since the drawer shipped, because the company cell is a link.
   > The replacement is true of the code as it stands and still forbids a dropdown, a split
   > button or a `<select>` in a row. It is NOT a licence for the outreach control: those
   > drafts live in the drawer footer next to Apply, where the posting is actually read.

   > **Amended 2026-09-09.** An Applied checkbox follows Apply in each row and also appears
   > at the end of the posting detail. Application status is private to this browser; it
   > does not mark the shared posting as applied for other readers.
5. **State lives in the URL.** Tab, filters, sort, and the open drawer are all search
   params. Back button works, filter sets are bookmarkable, and there is no client state library.

   > **Amended 2026-09-09.** Applied checkmarks and saved default preferences are private
   > browser state. Restored defaults become URL filters; shared cached pages stay impersonal.

## Tokens

All of them live in `app/globals.css` `:root`, copied from Postie's `public/style.css`.
Workie's older names (`canvas`, `surface`, `rule`, `fg`, `fg-dim`, `fg-faint`) point at
Postie's, so `text-fg-dim` and the CSS modules keep working.

| Role | Token | Value |
| --- | --- | --- |
| text | `--ink` | `#111318` |
| secondary text | `--muted` | `#6b7079` |
| hairline | `--line` | `#ececee` |
| soft fill (hover row, buttons) | `--soft` | `#f7f7f8` |
| hover / selected | `--hover` / `--active` | `#f1f2f4` / `#eceef1` |
| link, fresh | `--accent` | `#0a66c2` |
| primary button | `--primary` / `--primary-ink` | `#b9f081` / `#111318` |
| danger | `--danger` | `#b42318` |
| corners | `--r-xs` … `--r-xl` | 4 · 6 · 8 · 12 · 14px |

**Type — Inter, 14px/1.5.** Page title 20/600, section 16/600, strong 14/600, body 14,
secondary 13 muted, small 12 muted, label 11/600 caps at .06em.

**Components.** Buttons 34px, 8px corners, hairline border; lime primary. Inputs 34px,
`6px 10px`, focus border `#c9ccd2`. Pills 12/500, `2px 9px`, fully round; a chosen filter
pill fills with ink. Status pills use Postie's tinted pairs, each measured at AA. The table is
Postie's sheet: bordered wrap, caps heads on `#fbfbfc`, column rules. Drawer: hairline left
edge, `-12px 0 40px` shadow. Modal: 14px corners. Checkboxes tick in `#6fbf3a`.

**Contrast.** Every text pair is measured in `lib/contrast.test.ts`. Postie's control
borders (`--line`, `#c2c5cb`) are under 3:1 by design; controls read through their fill,
label and shape instead. Muted text on `--hover` is 4.44:1, so neutral pills sit on `--soft`.

## Motion Budget — three animations, total

Derived from `/emil-design-eng`'s frequency table, which is the governing authority
for a tool at this usage rate.

| Interaction | Frequency | Decision |
| --- | --- | --- |
| Tab switch | dozens/day | Indicator slides 150ms. Content swaps instantly. |
| Filter chip toggle → re-sort | dozens/day | **No animation.** Rows change. No FLIP, no layout reorder. |
| Row click → drawer | ~5/day | 220ms enter, 165ms exit, `translateX` + opacity, `cubic-bezier(0.32, 0.72, 0, 1)`. |
| Any pressable | constant | `:active { transform: scale(0.97) }`, 120ms. Not counted — it is feedback, not animation. |

`prefers-reduced-motion: reduce` → drawer becomes opacity-only, indicator snaps.

**Explicitly rejected, and why:**
- `/high-end-visual-design` §5 (scroll interpolation, staggered mask reveals, magnetic
  buttons) and §4C (`py-24`–`py-40` macro-whitespace) are marketing-page directives.
  Applied here they would cut visible rows by ~60% and animate a surface opened 20×/day.
  Its *craft* standards are kept: custom cubic-beziers, no banned fonts, GPU-only
  properties, nested bezel — but the bezel is used on the drawer only, never on rows.
- `/design-taste-frontend` §4 perpetual micro-interactions and §9 Bento archetypes.
  Same reason. Its `VISUAL_DENSITY` baseline of 4 is overridden to **8** (which then
  correctly triggers its own "Dashboard Hardening" ban on card containers),
  `MOTION_INTENSITY` 6 → **2**, and `DESIGN_VARIANCE` 8 → **3 for the table region**
  (a grid is the point; asymmetry there is hostile) / **6 for the page shell**.
- `/astryx` not adopted. It ships its own reset and token CSS; running it beside the
  specified Tailwind means two styling systems and two token vocabularies for a
  two-tab local app. Revisit only if a second consumer ever appears.

## States (all six required before any phase gate passes)

empty · loading · error · focus · disabled · zero-results-after-filter

The empty state teaches: it names the ingest command rather than saying "No jobs yet."
