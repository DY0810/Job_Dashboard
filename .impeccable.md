# Worky — Design Context

Produced by `/impeccable teach`, reconciled against `/emil-design-eng`,
`/design-taste-frontend`, `/high-end-visual-design`, `/minimalist-ui`, `/animate`.
This file is the tiebreaker when those skills disagree.

## Users

One person, job hunting for entry-to-mid **design** and **engineering** roles.
Sessions are long, repeated, and skew evening. The tool is opened many times a day
across weeks — this is a high-frequency instrument, not a destination.

**Job to be done:** *"Show me what landed since I last looked, in under two minutes,
so I can pick three things to apply to."* Everything else is secondary.

## Brand Personality

Three words: **unsentimental, fast, forensic.**

Not "modern," not "elegant," not "premium." The physical object this resembles is an
airport flight-strip board or a lab instrument readout — something that reports state
without editorializing. It never celebrates. It never nudges. It shows the rows.

## Aesthetic Direction

**Instrument-dense.** ~30 rows visible without scrolling. Hairline rules, not cards.
Tabular figures so timestamps and pay ranges align down the column. Chrome recedes
entirely; the data is the figure and the UI is the ground.

**Theme:** both, system-following (`prefers-color-scheme`), with a manual override.
Used at all hours, so neither theme is the "real" one — both get equal tuning.

**Anti-references:**
- LinkedIn Jobs — the thing being escaped. No feed, no engagement surface, no "people also viewed."
- The generic SaaS dashboard — no stat tiles, no sparklines, no gradient hero metric.
- Marketing-page choreography — no scroll reveals, no magnetic buttons, no perpetual motion.

**The one memorable thing:** the last 24 hours occupies its own band at the top of the
table, and nothing on the page competes with it for attention. The single accent color
exists to mark that band and nothing else.

## Design Principles

1. **Density is the feature.** Any change that reduces visible row count needs to buy
   something specific. Padding is not a feature.
2. **One accent, one meaning.** The accent marks *fresh*. It is never decoration, never
   a brand flourish, never a second button style.
3. **Motion only where it explains.** Frequency decides. Something touched 50×/day gets
   zero animation; something touched 5×/day may get 200ms. Three animations total in the app.
4. **Badges are controls.** Every badge is a live filter value — it must read as pressable
   without shouting. This is the only interactive affordance inside a row besides Apply.
5. **State lives in the URL.** Tab, filters, sort, and the open drawer are all search
   params. Back button works, filter sets are bookmarkable, and there is no client state library.

## Tokens

**Type — Archivo (Omnibus-Type), one variable family, three widths.**
Verify at implementation time that the Google Fonts variable cut exposes the `wdth`
axis; if it does not, fall back to static `Archivo` + `Archivo Narrow`.

| Role | Setting |
| --- | --- |
| Table rows | `wdth` ~85 — narrow buys column width, which is a functional reason, not taste |
| Drawer prose, filters | `wdth` 100 |
| Tab labels | `wdth` ~115, uppercase, wide tracking |
| All numerics | `font-variant-numeric: tabular-nums` |

Rejected as reflex or banned by one of the loaded skills: Inter, Geist, Space Grotesk,
IBM Plex, Satoshi, Outfit, Plus Jakarta Sans, Instrument Sans, Fraunces, Newsreader.

**Deliberate deviation:** `/design-taste-frontend` §6 mandates `font-mono` for all
numbers at density 8+. Archivo's tabular figures achieve the same column alignment
without a second family, so the intent is met and the letter is not. Recorded here so
nobody "fixes" it later.

**Color — OKLCH, accent is sodium amber (~hue 75).**
Departure-board phosphor. Deliberately not the blue/purple/cyan AI palette.

| Token | Light | Dark |
| --- | --- | --- |
| canvas | `oklch(0.975 0.006 75)` warm bone | `oklch(0.16 0.006 75)` tinted near-black |
| rule (hairline) | `oklch(0.90 0.008 75)` | `oklch(0.27 0.008 75)` |
| text primary | `oklch(0.25 0.01 75)` | `oklch(0.93 0.008 75)` |
| text secondary | `oklch(0.52 0.012 75)` | `oklch(0.66 0.010 75)` |
| accent (fresh) | `oklch(0.62 0.15 75)` | `oklch(0.78 0.14 75)` |

Never `#000` or `#fff`. Neutrals carry chroma 0.006–0.012 toward hue 75 so the accent
and the greys read as one system. Badges use surface + 1px rule, never the accent —
the accent means *fresh* and only *fresh*.

## Motion Budget — three animations, total

Derived from `/emil-design-eng`'s frequency table, which is the governing authority
for a tool at this usage rate.

| Interaction | Frequency | Decision |
| --- | --- | --- |
| Tab switch | dozens/day | Indicator slides 150ms. Content swaps instantly. |
| Filter chip toggle → re-sort | dozens/day | **No animation.** Rows change. No FLIP, no layout reorder. |
| Row click → drawer | ~5/day | 220ms enter, 165ms exit, `translateX` + opacity, `cubic-bezier(0.32, 0.72, 0, 1)`. |
| Any pressable | constant | `:active { transform: scale(0.97) }`, 120ms. Not counted — it is feedback, not animation. |

`prefers-reduced-motion: reduce` → drawer becomes opacity-only, indicator snaps.

**Explicitly rejected, and why:**
- `/high-end-visual-design` §5 (scroll interpolation, staggered mask reveals, magnetic
  buttons) and §4C (`py-24`–`py-40` macro-whitespace) are marketing-page directives.
  Applied here they would cut visible rows by ~60% and animate a surface opened 20×/day.
  Its *craft* standards are kept: custom cubic-beziers, no banned fonts, GPU-only
  properties, nested bezel — but the bezel is used on the drawer only, never on rows.
- `/design-taste-frontend` §4 perpetual micro-interactions and §9 Bento archetypes.
  Same reason. Its `VISUAL_DENSITY` baseline of 4 is overridden to **8** (which then
  correctly triggers its own "Dashboard Hardening" ban on card containers),
  `MOTION_INTENSITY` 6 → **2**, and `DESIGN_VARIANCE` 8 → **3 for the table region**
  (a grid is the point; asymmetry there is hostile) / **6 for the page shell**.
- `/astryx` not adopted. It ships its own reset and token CSS; running it beside the
  specified Tailwind means two styling systems and two token vocabularies for a
  two-tab local app. Revisit only if a second consumer ever appears.

## States (all six required before any phase gate passes)

empty · loading · error · focus · disabled · zero-results-after-filter

The empty state teaches: it names the ingest command rather than saying "No jobs yet."
